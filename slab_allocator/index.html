Crate slab_allocator

Source
Expand description

基于 Slab Allocator 的堆内存分配器 使用 Linked List Allocator 作为备选分配器，分配大于 4096 字节的内存

§Example

use slab_allocator::LockedHeap;

let mut heap = LockedHeap::empty();
unsafe {
   heap.lock().init(begin, size);
}
