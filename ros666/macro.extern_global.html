Macro extern_global

Source 
macro_rules! extern_global {
    ($symbol_name:ident) => { ... };
}
Expand description

返回一个指向全局符号的指针。 符号必须在二进制文件中定义。

extern_global!(symbol_name)

->

{
     unsafe extern "C" {
         fn symbol_name();
     }
     symbol_name as *const usize
}

§Example

.section .data
.global data_name
data_name:
   .quad 0x12345678
let data_name: *const usize = extern_global!(data_name);
