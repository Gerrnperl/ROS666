Macro info

macro_rules! info {
    ($fmt:expr) => { ... };
    ($fmt:expr, $($arg:tt)*) => { ... };
}
Expand description

记录信息级别的日志消息。

这个宏提供了两种用法:

  1. 不带参数的格式化字符串:
info!("这是一个信息日志");
  1. 带参数的格式化字符串:
info!("这是一个带参数的信息日志: {}", "参数值");

宏会在日志消息前添加绿色的 [INFO] 标签。

§参数

  • fmt: 格式化字符串。
  • arg: 可选的格式化参数。
