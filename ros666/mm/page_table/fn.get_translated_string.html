pub fn get_translated_string(token: usize, ptr: *const u8) -> String
Expand description

根据给定的页表 token 和指针，获取翻译后的字符串。

用于将一个指针指向的用户地址空间区域翻译为内核地址空间的字符串。内核可以通过字符串引用到用户地址空间的数据。

§参数

  • token: 页表的 token，用于从 SATP 寄存器中创建页表。
  • ptr: 指向内存区域的指针。

§返回值

返回一个包含翻译后字符串的 String 对象。
