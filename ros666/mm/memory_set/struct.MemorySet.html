地址空间

pub fn token(&self) -> usize

获取页表 token

token 即 satp (satp: Supervisor Address Translation and Protection) 寄存器的值

在启用 Sv39 页表时，satp 即作为三级页表的根节点。其第 60-63 位为模式位，为 0b100 时启用 Sv39 页表
