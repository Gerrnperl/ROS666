Macro debug

Source 
macro_rules! debug {
    ($fmt:expr) => { ... };
    ($fmt:expr, $($arg:tt)*) => { ... };
}
Expand description

打印调试信息的宏。

§参数

  • $fmt: 格式化字符串。
  • $($arg:tt)*: 可选的格式化参数。

§示例

debug!("这是一个调试信息");
debug!("这是一个带参数的调试信息: {}", 42);

该宏会在输出中添加 [DEBUG] 标签，并使用蓝色高亮显示。
